# Android Studio Badge 1 Unit Analysis

## Overview

This unit introduced the basics of Android development using **Kotlin** and **Jetpack Compose**.

The unit covered:

1. **Kotlin Fundamentals** – Variables, functions, classes, and lambdas.
2. **Add a Button to an App** – Creating buttons and handling user interactions.
3. **Interacting with UI and State** – Managing user input and updating the UI dynamically.

## What I Learned

Through these activities, I learned:

* How to use `val` and `var` in Kotlin.
* How to create and use functions.
* How to work with strings and basic calculations.
* How to create UI components using Jetpack Compose.
* How to handle button clicks and user actions.
* How state can be used to update the UI.
* How Kotlin and Jetpack Compose work together in Android development.

## Analysis

The activities helped me understand the basic process of developing an Android application. I first learned Kotlin programming concepts, then applied them to create UI components and handle user interaction. Finally, I learned how state allows the UI to change based on user input.

Overall, this unit gave me a basic foundation for developing interactive Android applications.
