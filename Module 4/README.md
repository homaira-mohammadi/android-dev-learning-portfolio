# Module 4 – Android Development

## Overview

In this module, I learned more advanced Android development concepts using **Jetpack Compose**, including architecture, navigation, and adaptive UI design.

## What I Learned

* How to use **ViewModel**, UI State, and StateFlow.
* How to build multi-screen apps using **Navigation**.
* How to pass data between screens.
* How to design layouts for different screen sizes.
* How Android app architecture helps organize application code.

## Apps Built

**Unscramble App** – Practiced ViewModel and state management.

**Cupcake App** – Practiced navigation and passing data between screens.

**Sports App** – Practiced adaptive layouts for different screen sizes.

## Analysis

This module helped me understand how Android applications can be structured, how different screens communicate, and how UI can adapt to different devices. It gave me more practical experience in building organized and interactive Android applications.
